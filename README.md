# Agent Playbook

给 AI 读的本地 agent 配置指南与踩坑索引。

## 这是什么

记录本地 agent 工具（Cherry Studio、hermes、opencode）的配置选择、插件选型和踩过的坑。目标不是写教程，而是让 AI 在装机或排障时知道**先查哪里**。

## 怎么用

把仓库交给 agent，它会先读 `AGENTS.md`：

| 文件 | 内容 |
|---|---|
| `AGENTS.md` | AI 入口、五条规则、路由表 |
| `config.md` | 能力增强、网络前提、Cherry Studio 设置 |
| `traps.md` | 症状 → 先查什么 → 搜索词 |

## 原则

- **只指路，不抄答案**：安装命令、版本号从上游链接现场获取
- **只记录搜不到的东西**：个人选型、本机设置、踩过的坑
- **一条一两行**：不写长文，方便维护

## 平台

Windows / macOS / Ubuntu。
